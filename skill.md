# Design Skill: Dark AI / Neon Portfolio Landing

## Главная задача
Довести сайт-портфолио до уровня стильного digital-продукта, а не учебного проекта.

Сайт должен выглядеть как современный AI / fintech / vibe-coding интерфейс:
- тёмный
- технологичный
- чистый
- с яркими акцентами
- с ощущением системы, панели управления и digital-лаборатории

## Визуальный стиль

Основной стиль:
Dark AI Interface / Neon Fintech / Digital Lab

Ассоциации:
- AI-система
- панель управления проектами
- digital-студия
- прототипирование
- автоматизация
- vibe-coding

Нельзя:
- делать сайт слишком светлым
- использовать кислотный хаос
- делать дешёвый cyberpunk
- перегружать анимациями
- делать вид обычного резюме
- использовать скучные серые карточки без глубины

## Фон

Добавить:
- тёмный градиент
- едва заметную сетку
- мягкие размазанные glow-пятна
- тонкие линии интерфейса
- аккуратные световые акценты вокруг важных блоков

Фон не должен мешать чтению текста.

## Hero-блок

Hero должен быть самым сильным блоком.

Слева:
- крупный заголовок
- понятный оффер
- две кнопки
- бейдж “AI / SMM / vibe-coding”

Справа:
- визуальный AI-control panel
- строки состояния
- прогресс-бары
- мини-схема Idea → Logic → Prototype → Launch
- эффект терминала или панели управления

Hero должен создавать ощущение:
“Передо мной человек, который умеет собирать современные digital-продукты”.

## Карточки

Все карточки делать в стиле:
- glassmorphism
- тёмный полупрозрачный фон
- тонкая светлая рамка
- мягкое свечение при наведении
- скругление 24–32 px
- аккуратная тень

Hover:
- лёгкий подъём
- усиление рамки
- мягкое свечение
- без резких скачков

## Проекты

Карточки проектов должны выглядеть как кейсы.

У каждой карточки:
- название
- тип проекта
- описание
- список функций
- статус
- кнопка действия

Визуально проекты должны быть самым убедительным блоком после Hero.

Не использовать формулировки:
- “учебный”
- “новичок”
- “простой проект”

Лучше:
- “первый digital-прототип”
- “демонстрация подхода”
- “проект в развитии”
- “готов к демонстрации”

## Блок “Решения под ниши”

Этот блок должен показать продуктовый подход.

Смысл:
специалист не просто делает сайты, а подбирает digital-формат под задачу бизнеса.

Оформить карточками:
- бухгалтерские услуги
- цветочный бизнес
- другие ниши

Внутри показывать модули:
сайт, бот, AI-ассистент, калькулятор, квиз, игра, мини-приложение.

Модули можно оформить как маленькие pills / tags.

## Анимации

Добавить только аккуратные анимации:
- плавное появление блоков
- лёгкий hover на карточках
- мягкий glow
- медленное движение фоновых пятен
- небольшое мерцание статуса в Hero

Не использовать агрессивные анимации.

## Адаптивность

На мобильном:
- hero в одну колонку
- карточки по одной
- кнопки крупные
- текст хорошо читается
- не должно быть горизонтального скролла

## Тон сайта

Сайт должен звучать уверенно, но честно.

Не писать:
“Я новичок”
“Я только учусь”
“У меня мало опыта”

Писать:
“Собираю первые digital-проекты”
“Тестирую разные форматы”
“Создаю рабочие прототипы”
“Развиваю портфолио через реальные задачи”

## Финальная цель

После применения этого skill.md сайт должен выглядеть как стильное портфолио начинающего, но перспективного AI / digital-специалиста, который умеет мыслить не только дизайном, но и бизнес-логикой.

## Важно: проект статический

Сайт должен остаться простым статическим сайтом для GitHub Pages.

Нельзя:
- подключать React
- подключать Vite
- требовать npm install
- использовать Node.js
- добавлять зависимости
- использовать CDN-библиотеки

Можно:
- HTML
- CSS
- чистый JavaScript
- CSS-анимации
- встроенные SVG
- адаптивную вёрстку
